# SAND — 战术射击原型

浏览器里运行的第一人称战术射击游戏原型，手感靠近 CS（急停更准、移动散布大、爆头四倍伤害、护甲按 CS 公式减免、回合经济）。地图、武器和音效全部原创 / 程序化生成，不包含任何 CS:GO 原版资源或商标。

## 如何运行

需要 Node.js 18+。

```bash
cd D:\code\groktest
npm install
npm run dev
```

浏览器打开终端里提示的地址（默认 [http://localhost:5173](http://localhost:5173)）。点击「加入 ATK」或「加入 DEF」，再点击画面锁定鼠标即可操作。

```bash
npm test      # 命中、护甲、经济、后坐力单元测试
npm run build # 类型检查并打包
```

## 实现的系统

- **移动**：Source 风格的 `sv_accelerate` / `sv_friction` / 空气加速，60Hz 固定逻辑步长 + 渲染插值。
- **武器**：AK（步枪）、PX9（手枪）、FALCON（狙击）、BLADE（近战）。独立伤害、射速、弹匣、后坐力、穿甲。
- **射击**：射线命中，散布随移动/跳跃/下蹲变化，后坐力前 10 发上扬、之后横向摆动，停火 0.4 秒后回正。
- **命中**：head / chest / stomach / leg，倍率 4.0 / 1.0 / 1.25 / 0.75。护甲公式见下。腿部不受护甲保护；爆头无头盔不减伤。木板可穿透并衰减伤害，水泥不可穿透。
- **回合**：15 秒准备（冻结、可买枪）→ 1:55 交战 → 结算。先到 13 分获胜，12 回合后交换阵营并重置金钱。
- **炸弹**：下包 3.5 秒，40 秒爆炸；拆包 10 / 5 秒。
- **经济**：击杀奖励按武器类型（步枪 $300、手枪 $300、近战 $1500、狙击 $100，对齐 CS 规则而非一律 $600）。胜 $3250，败 $1400 起按连败 +$500 至 $3400。下包/拆包各 $300。
- **Bot**：5 个 bot（3v3），巡逻 / 遭遇 / 交战 / 掩护 / 撤退，A* 导航，反应延迟与瞄准误差。
- **地图 SAND**：对称双包点 + 中路 + 双方出生点。
- **HUD / 音效**：血量、护甲、弹药、金钱、比分、计时、动态准星、击杀提示、受击方向；脚步/开枪/换弹/命中/爆炸/拆包滴答均为 Web Audio 合成。

## 手感与数值说明（与 CS 的差异）

- 单位与官方一致：重力 800、跳跃初速 301.99、身高 72 / 蹲 54、视高 64，步枪移速 215。1 unit ≈ 0.01905 m。
- 护甲：生命受到 `伤害 × 穿甲系数`，护甲扣除被吸收部分的 50%。数值写在 `src/config.ts`。
- 击杀奖金按 CS 规则实现（见上），没有采用「手枪/刀/狙一律 +600」。
- 半场在第 12 回合结束后交换阵营，金钱重置为 $800，连败奖励清零。
- 未做跳中连跳、急停的完整加速表微调、闪光弹与道具。后坐力是原创曲线，不是 AK 的逐发表拷贝。

## 已知缺陷

- 没有联机、完整观战产品化、HE/燃烧弹、武器检视与复杂观模型动画。
- 导航网格由碰撞盒采样生成，个别角落可能绕路或短暂卡住。
- Bot 会买 AK 和头盔，策略偏简单，残局和假拆比较弱。
- 地图是抽象几何体，不是完整社区地图的比例复刻。
- 部分显示器在超高刷新率下只保证逻辑 60Hz，画面会插值。
